# Projekt

En personlig startsida som samlar länkar till alla mina publicerade webbprojekt på ett ställe.

**Live:** https://vg1414.github.io/Projekt/

## Funktioner

- Ett kort per projekt med appens egen logga, kort beskrivning och adress
- Projekten i tre storlekar efter hur stora de är: Reduceraren och Krokens Copa störst, sedan Bokis, ABC & 123 och Black Book, sist de mindre
- Ljust och mörkt läge följer enhetens inställning
- Fungerar på mobil (kan läggas på hemskärmen)
- Dold för sökmotorer (`noindex`), sidan är för eget bruk

## Lägga till ett projekt

1. Lägg appens logga (helst 192×192 px) i `logos/`.
2. Lägg till projektet i listan `P` i `index.html` (namn, tagg, logga, färg, beskrivning, adress).
3. Placera det i rätt nivå i `GROUPS`.
